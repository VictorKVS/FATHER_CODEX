TIMA: лаборатория моделирования угроз

Пять связанных этапов: найти угрозы, построить дерево возможной атаки, оценить актуальность, рассмотреть риск и доказать работоспособность защитных мер. Учебный объект — документный AI-агент с RAG и UAG.

Текущий статус: браузерный учебный тренажёр и архитектурная спецификация. Это не анализ работающего стенда, не готовая интеграция TIMA с ALINA/POLYGON, не автоматическая оценка по методике ФСТЭК и не результат сканирования. Матрица 5×5 — условная корпоративная шкала, а не нормативный расчёт.

Пользователь→API/AuthN→UAG / Policy→AI Agent→RAG→Document Store

Проверь входную идентичность, разрешённое действие, права на объект, границы между источником документа и инструкциями агента, аудит вызовов и последствия для владельца данных.

3. Дерево атаки AND/OR — интерактивно

Корневая цель — получить документ без необходимых полномочий. У каждого пути несколько условий, объединённых AND. Для достижения цели достаточно любого пути — OR.

ЦЕЛЬ (OR): несанкционированно получить документ
Путь A — чужая личность (AND)
  • Получены чужие учётные данные
  • Система допускает вход с ними
Путь B — ошибка API (AND)
  • Запрошен чужой объект
  • Нет надлежащей проверки прав на объект
Путь C — ошибка RAG (AND)
  • Общий индекс содержит закрытый документ
  • Нет фильтра полномочий
  • Нет повторной проверки при выдаче

Отметь только условно доказанные меры; это меняет изображение дерева, но не состояние реальной системы:

Упрощение: в реальности каждая мера снижает риск с определёнными предпосылками, а дерево никогда нельзя считать автоматически полным.

4. Матрица рисков 5×5 — учебная

Индекс = произведение порядковых уровней только для учебного ранжирования. Это не статистическая вероятность, не финансовая оценка и не подмена определения актуальности угроз по ФСТЭК. Значения источников и допущения должны сохраняться отдельно.

Принцип fail-closed: отсутствие актуальной базы CVE, доказательств, владельца риска или обязательной проверки означает REVIEW_REQUIRED/BLOCKED, а не PASS. TIMA не может подписывать релиз или принимать существенный остаточный риск вместо человека.
