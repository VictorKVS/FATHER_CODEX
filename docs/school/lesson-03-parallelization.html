01 · История

Школьная исследовательская экспедиция

Ты готовишь доклад о планетах. Первый помощник пишет краткое описание, второй придумывает вопросы, третий составляет словарь терминов. После них редактор собирает общую работу.

Тема исследования
→
Агент А — описание
Агент Б — вопросы
Агент В — термины
→
РедакторЖдёт все результаты
Главная мысль: одновременно можно выполнять только независимые задачи. Редактору нужны результаты трёх помощников, поэтому он начинает после них. Эта схема называется fan-out → fan-in.
02 · Полная теория

Что необходимо понять

Последовательно

Вторая операция начинается после первой. Общее время складывается из длительностей шагов.

Конкурентно

Независимые операции продвигаются одновременно, в том числе когда ожидают API или диск.

Синхронизация

Сборщик ждёт нужные результаты. Если один не готов, итог может оказаться заблокированным.

Компромисс

Обычно сокращается ожидание, но растут сложность, нагрузка, расходы на сопровождение и диагностику.

Это не ускорение любого кода

Python asyncio организует конкурентное выполнение ожиданий ввода-вывода, но само по себе не запускает тяжёлые вычисления одновременно на нескольких ядрах.

Цена и качество результата

Нельзя утверждать, что параллельные запросы автоматически дешевле. Число запросов, токенов и проверок может остаться прежним или увеличиться.

04 · Найди ошибку

Когда одновременно нельзя?

Пример 1

Сначала получить текст статьи, потом перевести этот текст. Можно ли начать перевод до получения статьи?

Пример 2

Один агент ищет сведения о Марсе, второй — о Венере. Их результаты пока не используются друг другом.

06 · Python для ученика

Читаем настоящий алгоритм

import asyncio async def research(name: str, delay: float) -> str: await asyncio.sleep(delay) # имитация ожидания return f"{name}: готово" async def main() -> list[str]: results = await asyncio.gather( research("Описание", 0.1), research("Вопросы", 0.2), research("Термины", 0.1), ) return list(results) if __name__ == "__main__": print(asyncio.run(main()))

Это автономная учебная программа из стандартной библиотеки Python. Она использует задержки для имитации ожидания, а не реальные LLM-запросы. Для промышленного агента потребуются тайм-ауты, обработка ошибок, допуски и измерения.
