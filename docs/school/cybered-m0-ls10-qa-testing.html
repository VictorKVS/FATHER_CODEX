3. Инженерный разбор и акценты для собеседования

QA и тестирование

QA организует качество процесса, тестирование проверяет конкретные свойства продукта.

Unit tests

Проверяем небольшие единицы изолированно, включая ошибки и отказы.

Integration tests

Проверяем стыки систем: API → UAG → хранилище.

Functional tests

Сверяем результат с бизнес-требованием и acceptance criteria.

Security tests

Проверяем запрещённые действия, утечки, ошибки контроля доступа.

Automation

Повторяемость требует контролируемых зависимостей и честных ожидаемых результатов.

White-box / black-box

Классификация по доступности знаний о реализации, не синоним уровней тестирования.
