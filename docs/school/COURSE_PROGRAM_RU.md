# FATHER AI Academy — учебная программа 12–17 лет

**Версия:** 0.1, 2026-11-25.  
**Источник тем:** Antonio Gulli, *Agentic Design Patterns*. Соответствие семи тем главам 1–7 пользовательского оригинала и предоставленным ссылкам на русский перевод TaiPanCy.  
**Статус:** COURSE_DESIGNED / CH01–CH03_INTERACTIVE_MVP / CH04–CH07_PLANNED / EDUCATIONAL_VALIDATION_NOT_YET_DONE.  
**Сайт:** [index.html](index.html).

## Для кого

- 12–14 лет: визуальные схемы и игровые алгоритмы, без обязательного программирования.
- 15–17 лет: логика, JSON, Python и эксперименты.
- Углублённый трек: LLM API/Ollama, доказательства работы, FinOps и безопасность. Только при сопровождаемой преподавателем лаборатории и разрешённом доступе к моделям.

**Цель:** ребёнок умеет не только создавать промпт, но и выбирать алгоритм, проверять результаты, отличать модель от инструмента и понимать ограничения и стоимость.

## Обязательная система усвоения всей теории

См. [THEORY_MASTERY_SYSTEM_RU.md](THEORY_MASTERY_SYSTEM_RU.md). Каждый раздел авторской главы должен быть сопоставлен с карточками понятий, объяснениями по возрастам, иллюстрациями, контрпримерами, проверками объяснения своими словами, переноса знаний и отложенного повторения. Успешно собранный алгоритм **не равен** усвоенной теории. Тренер и POLYGON проверяют разные стороны компетенции.

## Требования к школьному курсу

1. Русский основной; английские термины с произношением и словарём.
2. На каждый паттерн: комикс/история, авторская SVG-схема, анимация/симулятор, версия для начинающих, версия Python, тесты, задание для самостоятельной работы.
3. Достоверность: цитирование оригинальной главы и границ объяснений; не републиковать полный текст или картинки книги.
4. Доступность: keyboard, понятные цвета и подписи, мобильный интерфейс, поддержка сниженной анимации.
5. Безопасность детей: нет регистрации, рекламного трекинга, сбора имён или личных данных; задания не требуют передачи персональных данных в LLM.
6. Безопасность API: в публичном браузере никаких ключей; модельные вызовы только через контролируемый backend с расходными лимитами и разрешением.
7. Измеримые исходы: объясняет алгоритм; строит верный pipeline; воспроизводит проверку; распознаёт ошибки; сравнивает стоимость; проходит экзамен.
8. Качество: результат учебной игры не равен POLYGON-квалификации промышленного агента.

## Учебный конвейер производства уроков

```text
Книга / глава -> source review -> учебные цели / возраст
 -> сюжет + метафора -> схема -> интерактивный симулятор
 -> тестовые примеры и ошибки -> контроль знаний
 -> доступность -> преподавательская проверка
 -> публикация / аналитика только без личных данных
```

## Разделение статусов

- `SOURCE_REVIEWED` — прочитан первоисточник и отмечены страницы.
- `LESSON_DRAFTED` — готов объяснительный материал.
- `INTERACTIVE_MVP` — есть работающий учебный прототип.
- `CLASSROOM_TESTED` — проверено на реальной группе с согласиями и измерением понимания.
- `QUALIFIED` — независимая оценка методики и исполнения.

**Текущий курс пока не является педагогически квалифицированным**; реального пилотного испытания со школьниками не проводилось.
