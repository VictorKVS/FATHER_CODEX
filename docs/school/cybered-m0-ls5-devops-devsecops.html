3. Четыре подхода: что различать на собеседовании

Waterfall

Последовательные фазы разработки. Уместен при относительно стабильных требованиях, формальном контроле и регулируемых согласованиях.

Agile / Scrum

Agile — ценности адаптивной разработки. Scrum — фреймворк с Product Owner, Scrum Master, Developers, спринтами и backlog.

DevOps

Совместная ответственность Dev и Ops, автоматизация CI/CD, инфраструктура как код, быстрые обратные связи и наблюдаемость.

DevSecOps

Безопасность с момента постановки требований до эксплуатации: модель угроз, SAST, SCA, SBOM, политики выпуска, аудит.

4. Полный конвейер FATHER / TIMA

IDEA+ / S0→Security Requirements→STRIDE / S2→FATHER_CODEX→CI + TIMA→POLYGON→CD / Monitoring

Security Gates и S0–S7 могут использоваться в итерационной разработке и не означают обязательный Waterfall. TIMA обеспечивает управление проверками; ALINA связывает результаты с доказательствами, POLYGON проводит независимые испытания, а уполномоченное лицо принимает существенные остаточные риски.

Практическое упражнение. Спроектируй workflow GitHub Actions: `commit → unit tests → SAST → SCA → SBOM → publish artifact → manual approval → deploy`. Для каждого шага укажи проверяемый результат, поведение при ошибке и ответственного.

6. Экзамен перед собеседованием

В чём суть Waterfall?

Последовательный жизненный цикл с фазами и формальными контрольными точками. Возможны возвраты и корректировки.

Чем Agile отличается от Scrum?

Agile — принципы и ценности; Scrum — конкретный фреймворк для командной работы. Scrum не заменяет обязательные требования безопасности.

Что такое DevOps?

Взаимодействие разработки и эксплуатации с совместной ответственностью, обратной связью и автоматизацией создания, доставки и поддержки приложений.

Что такое DevSecOps?

Интеграция безопасности в жизненный цикл разработки и эксплуатацию наравне с качеством, доступностью и скоростью изменений.

CI и CD — одно и то же?

Нет. Continuous Integration — частое объединение изменений и тестирование; Continuous Delivery — готовность доставить проверенный выпуск; Continuous Deployment — автоматическое развёртывание.

Почему установка Trivy ещё не означает внедрение DevSecOps?

Нужно подтвердить актуальность базы, выполнение проверок, анализ находок, исправление, повторное тестирование, критерии отказа и evidence.

Как обеспечить воспроизводимость?

Фиксировать исходники, версии инструментов и зависимостей, контролировать конфигурацию, тестовые данные и артефакты. Побайтово воспроизводимая сборка — более строгое свойство, чем похожие тестовые стенды.
